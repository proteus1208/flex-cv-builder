# CV Generator

Windows standalone app that merges **any-structure CV JSON** into a **DOCX template** using `${...}` placeholders, then exports:

- `resume.json`
- `resume.docx`
- `resume.pdf` (via LibreOffice)
- `notes.txt` (from JSON `notes`)

Output folders:

```text
{OutputRoot}/{yyyy-MM-dd}/{name} - {role} - {skill1}-{skill2}-{skill3}/
```

The output root is remembered in `%AppData%/CvGenerator/settings.json`.

## Requirements

| Machine | Need |
| --- | --- |
| Build (Windows recommended for the UI) | .NET 10 SDK |
| Run (other PCs) | **No .NET install** if you use `scripts/build-single.sh` |
| Run | [WebView2 Evergreen](https://developer.microsoft.com/microsoft-edge/webview2/) (included on most Win10/11) |
| PDF | [LibreOffice](https://www.libreoffice.org/) (`soffice`) installed |

## Placeholder syntax

| Token | Meaning |
| --- | --- |
| `${name}` / `${linkedin}` | JSON field (dotted paths supported) |
| `${ArrayStart experience}` … `${ArrayEnd experience}` | Repeat everything between (paragraphs, tables, images) for each array item |
| `${experience_i.title}` | Field on the current loop item (`arrayname_i.field`) |

Nested loops are supported (ArrayStart/ArrayEnd inside another block). Template styles (font, color, alignment, borders) are preserved; only placeholder text is replaced.

Example:

```json
"experience": [
  { "title": "Eng", "company": "A" }
]
```

```text
${ArrayStart experience}
${experience_i.title} — ${experience_i.company}
${ArrayEnd experience}
```

## Bold and hyperlinks inside JSON values

Use lightweight markup in string fields:

| Markup | Result |
| --- | --- |
| `**text**` | Bold |
| `[label](https://example.com)` | Clickable hyperlink |

```json
{
  "summary": "Shipped **PDF** export and **DOCX** merge",
  "linkedin": "[Cody Lee Berry](https://linkedin.com/in/example)"
}
```

Template tip: you can also make the whole `${placeholder}` bold/colored in Word — that style is kept as the base, and `**...**` / links add on top.

Links must be `http`, `https`, or `mailto`.

## Scripts

**Windows (PowerShell):**

```powershell
.\scripts\dev.ps1           # run UI
.\scripts\build.ps1         # framework-dependent publish
.\scripts\build-single.ps1  # self-contained single-file → artifacts\CvGenerator\
```

If PowerShell blocks scripts:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

**Git Bash / Linux:**

```bash
chmod +x scripts/*.sh
./scripts/dev.sh
./scripts/build.sh
./scripts/build-single.sh
```

## UI layout

1. **Top** — app title + remembered output root  
2. **Left** — CV JSON editor  
3. **Right** — template picker, placeholder map, output path preview  
4. **Bottom** — Debug Error List (filter / copy / clear)  
5. **Action bar** — Generate All + status (`Ready` / `Success` / `Partial` / `Failed`)

PDF failure with successful DOCX/JSON/notes → **Partial** (not silent success).

## Develop libraries / tests on Linux

```bash
export PATH="$HOME/.dotnet:$PATH"
dotnet test tests/CvGenerator.Core.Tests
dotnet test tests/CvGenerator.Docx.Tests
```

The WPF Blazor UI targets `net10.0-windows` and must be built/run on Windows.
